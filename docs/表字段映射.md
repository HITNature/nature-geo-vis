## 更新命令

```bash
# 1. 用新库覆盖根目录 geodatabase.db（本地操作，不提交）
# 2. 合并属性 / 导出 POI
npm run update-from-nc
# 3. 重建运行库
npm run import-data
# 4. 上云：见 数据更新与上云文档.md §4
```

## 注意与避坑

- **OBJECTID 漂移（城市 / 初中 POI）**  
  - 现象：旧 `cities.geojson` 中 `OBJECTID: 105` 可能是绥化，新库同 ID 可能是丹东。  
  - 后果：按 ID 合并会导致边界与属性「张冠李戴」。  
  - 做法：`updateCities` / `updateJsPois` **必须按名称对齐**。

- **网格仍用 OBJECTID 挂几何**  
  - 原因：分片几何来自历史投影结果，日常只刷属性。  
  - 省份纠偏：用 `city_level` 的城市名映射覆盖 `GCs_level` 中错误的 `province`（如哈尔滨被写成吉林等）。

- **大文件不上 Git**：`data/geodata.db`、`cells_chunks/` 等；上线需 Release + Railway `GEODATA_DB_URL` / `GEODATA_DB_SIZE`。

- **地图底图**：CARTO `dark_all` + `.dark-map-tiles` CSS 滤镜微调亮度，避免改浅色底破坏对比度。

- **城市 Tooltip**：对空名 /「未知区域」不绑定，避免脏数据。

- **搜索框**：嵌在左下角图例内；选中推荐项时用 `isSelectingRef` 拦截二次防抖请求。
